# 学习小助手 · DSH 插件壳

在 DSH 里旁听开发过程：你在会话里追问「为什么/怎么不对」，或工具报了非操作性错误时，插件把这段信号交给本机学习小助手；它判断「这条值不值得现在讲」，值得就生成一张知识卡。启用前的旧会话也能扫一遍，把还没被卡片覆盖的开发片段补成「历史卡片」。

## 出现在哪里

- 右下角一枚书本角标，有卡片时右上角显示数字。
- 卡片站顶栏右侧显示「总数 +n」：`+n` 是还没翻开的新卡；翻开一张减一，全部看过只剩总数。新卡累积会变成 `27 +2`。
- **点了才展开**，不抢焦点、不出声、不发系统通知；一次只出现一张。
- 卡片上可以点「懂了 / 没懂 / 太简单」，也可以取下一张待看。
- 没有合适选项的卡（如工作流/判断卡）自动进入「先想后看」模式：不伪造「我不知道」单选项，先在心里过一遍再翻面。
- 知识库条目可以点「看全文」。
- 面板里的「卡片站」在 DSH 内用浮层打开完整卡片站，不另开浏览器。
- 面板下方是「历史卡片」：可手动「扫描历史」，插件启动后也会自动补一次（12 小时内只一次）；补出来的卡和已处理的实时旁听都留在这里。
- 回溯范围默认每个旧会话最近 8 轮对话，也可以在设置页改成最近 N 天。
- 右键会话标题（或「…」菜单）可单独关闭/开启这个会话的扫描；关闭后不送实时信号，也不参与历史补课。
- 卡片站默认跟随 DSH 深浅色；右上角「深色/浅色」可手动切，选择会记住。

## 兼容性

- 主验证环境：DSH 0.2.2-rc.3。
- 没有 `webServer` 服务的旧版本（如 0.2.1-rc.2）不会再让插件挂起；代理不可用时客户端回退到 4780 直连。
- 卡片站独立设置页：`http://127.0.0.1:4780/settings.html`。

## 自动启动

插件会随 DSH 自动拉起：

- 卡片站 `app/src/serve.mjs`（4780）
- 知识库 `~/rag/kb_server.py`（8790）
- 本地 `ollama serve`（可选；仅当 `localJudge.enabled` 且配置了可执行文件；模型按需加载；没填 API 时也负责历史补课）。没有本地模型时，灰区判定自动用设置里的 API 做小请求。

启动日志在 `app/data/auto-start.log`。插件停用/卸载时只停自己拉起的进程，原本手动开着的服务不受影响。**不要同时跑 watch.mjs**，否则同一信号会送两遍。

历史补卡的模型顺序由设置页决定：API / 本地 Ollama / DSH 三档各用一次，用户自己排优先级；前面的不可用才往后走。API、优先级、回溯范围都在 **插件 → 学习小助手 → 配置**，不用改文件。

端口不同时改插件配置的 `baseURL`；学习小助手不在插件隔壁时改 `appDir`。

历史补卡会先对比现有卡片和知识库，已覆盖的点不重复生成；角色扮演/文件整理类会话不参与；生成的卡同样受 50 张未学上限约束，到上限会明确报错而不是静默丢弃。

## 行为边界

- 只旁听顶层会话，子代理会话不送信号。
- 不等用户发问：助手在任务中讲出「关键/本质/取舍/结论/原则/先…再…」等判断时，消息一到就本地匹配已有卡片；命中出卡/角标。主动扫描同会话 5 分钟最多一次。
- 卡片、知识库都没命中时，后台只做一次小请求生成「种子卡」（标题/结论/逐字引文），面板显示「新知识点」；点「展开细讲」才走完整制卡与校验。种子卡不进卡片库、不占 50 张上限；种子优先 API，其次 DSH，不自动用本地 27B。
- 工具层的操作性报错（编辑冲突、被中断、沙箱拒绝等）不送。
- 学习小助手没启动时，角标变灰；点开只显示启动提示，不会反复弹窗。
- 关闭 DSH 后，插件拉起的服务会随插件停用而停止；卡片数据都在本地，不上传。

## 配置

在 profile 的 `cordis.patch.yml` 里覆盖：

```yaml
- id: learning-assistant
  config:
    baseURL: http://127.0.0.1:4780
    appDir: ./app
    kbDir: ~/rag
    autoStartOllama: true
    ollamaBin: /opt/homebrew/bin/ollama
```
