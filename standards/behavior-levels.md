## 二、三层测试（从便宜到贵）

### 层 1：规则单测（离线，10 分钟，不依赖你）

用合成历史跑固定用例，确认规则本身没写错：

| 用例 | 输入 | 期望 |
|---|---|---|
| 两种题型 + 隔 8 天 | 识别对 + 因果对，`rung_at` 在 8 天前 | 升 1 档 |
| 两种题型 + 同一天 | 识别对 + 因果对，`rung_at` 是今天 | 不升 |
| 只答对一种题型 | 识别对 ×3 | 不升 |
| 答错 | 识别对 + 应用错 | 掌握度降，档位不变 |
| 手动太浅 | 点「太浅了」 | +1，最高 G4 |
| G4 再点 | 已 G4 点「太浅了」 | 不变，按钮置灰 |
| 连续两次答错 | 暂无实现 | **标红：这是待补的规则** |

**通过标准**：7 条全过；最后一条先记为「待实现」，不在这次验收里。

### 层 2：历史回放（离线，5 分钟）

拿现有 34 条复习记录 + 4 条曝光回放：

- 每次升档/降档，人工检查「这次升档有没有行为依据」；
- 输出一张对照表：`行为 → 算法判断 → 我的判断`；
- 统计不一致率。

**通过标准**：不一致 ≤10%（3 条以内）。样本只有 34 条，这一层只当 sanity check，不当最终结论。

### 层 3：真机小实验（需要你 5 天 × 10 分钟）

这是唯一能回答「行为能不能代替自评」的测试。

**题面**：12 张卡，四条线各 3 张，覆盖 G0 / G2 / G4 三档（每档 4 张）。
**流程**：每天做 3 张，共 5 天（第 5 天剩 3 张 + 回看）。
**每次记录 5 个信号**：

1. 答对 / 答错（已有）；
2. 答题用时（毫秒）；
3. 有没有点「看提示 / 再举个例」（新增记录字段）；
4. 有没有点「没懂 / 太浅了」（已有）；
5. 做完后自评难度 1–5（新增一个 5 档小条，放在卡背，和现有「懂了 / 没懂」并排，不替换）。

**要验证的三个假设**：

| 假设 | 指标 | 通过线 |
|---|---|---|
| H1 档位越高越难 | 同一概念 G0→G2→G4 的正确率单调下降 | 至少 8/12 张符合 |
| H2 行为能预测难度 | 用时 + 是否看提示 + 对错 → 预测自评难度 | AUC ≥ 0.70 |
| H3 系统和你的感觉一致 | 算法判「该升档」时你自评「太浅」的比例 | ≥ 80% 一致 |

**如果 H1 不成立**：说明卡片的 G 档位标错了，先修卡，不修算法。
**如果 H2 不成立**：说明行为信号不够，退回「只用对错 + 手动」，不要硬上模型。
**如果 H3 不成立**：升档规则要放宽或收紧，进第二轮实验。
