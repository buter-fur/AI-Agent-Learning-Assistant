> 仓库包含三部分：DSH 插件壳（根目录）、主项目卡片站（`app/`）、知识库与卡片标准（`standards/`、`knowledge-base/`）。主项目不包含个人会话数据、卡片数据库或 API Key。

# dsh-plugin-learning-assistant

把本机「学习小助手」接进 DeepSeek Harness：你在会话里追问「为什么/怎么不对」或工具报出非操作性错误时，插件把信号交给学习小助手；它判断值不值得讲，值得就在 DSH 右下角放一枚书本角标，点开是一张知识卡。启用插件前的旧会话也会被扫一遍，把还没有卡片覆盖的开发片段补成「历史卡片」。

## 主项目与标准

- `app/`：卡片站主项目（Node + SQLite，含卡片流/答题/概念图/知识地图/历史补卡/种子卡）
- `standards/`：知识库内容、分片、API、标签词表、卡片库分工、四条线、行为判级、价值分、周报等标准
- `knowledge-base/`：空知识库模板，不含个人会话数据

## 兼容性

- 主验证环境：DSH **0.2.2-rc.3**（桌面版）。
- 0.2.1-rc.2 这类没有 `webServer` 服务的版本：插件不再因 `inject` 缺失而挂起；代理不可用时，客户端会回退到 `http://127.0.0.1:4780` 直连（卡片站已开 CORS）。
- 独立使用卡片站时，API 配置入口在 `http://127.0.0.1:4780/settings.html`，不需要先让插件加载成功。
- Windows：双击 `app/启动学习小助手.bat`，或 `node app\src\serve.mjs --open`；只需要 Node ≥ 22.13。

## 依赖与启动

插件会随 DSH 自动拉起本机服务，正常使用**不需要手动启动**：

- 卡片站：`app/src/serve.mjs`（本地开发时也会自动找 `../学习小助手/app`），默认 `127.0.0.1:4780`
- 知识库：`~/rag/kb_server.py`，默认 `127.0.0.1:8790`
- 本地 27B（可选，灰区判定；没填 API 时也负责历史补课）：若 `config.localJudge.enabled` 且系统里有 `/opt/homebrew/bin/ollama`，会自动拉起 `ollama serve`；模型按需加载。

插件停用/卸载时会停掉**它自己拉起**的进程；原本已经由你手动开着的服务不会被杀掉。启动日志在 `app/data/auto-start.log`。

如果学习小助手不在插件隔壁，配置 `appDir` / `kbDir`；不要启动 `watch.mjs`，否则同一信号会送两遍。

## 安装

DSH → 插件 → 添加插件 → 选择本目录；或者在支持 `plugin_manager` 的会话里安装当前目录。装好后在 **插件** 页确认「学习小助手」一行已启用。

改过 `client.js` 后需要重载/重启一次 DSH 才拿到新浏览器半边；之后的日常使用不需要重启。

## 卡片站顶部计数

卡片站顶栏右侧显示「总数 +n」：

- 总数是当前卡片站里的卡片数，`+n` 是还没翻开过的新卡。
- 翻开一张卡（点「看答案」翻到背面）后，`+n` 自动减 1；全部看过就消失，只剩总数。
- 新卡继续进来会累积，例如 `26 +1` → 没看又新增一张 → `27 +2`。
- `+n` 用朱砂红底白字，和通知角标一样；页面每 20 秒刷新一次数字。

## 历史补卡

面板里实时卡片下方是「历史卡片」：

- 打开面板后点「扫描历史」，或插件启动 8 秒后在后台自动补一次（12 小时内只自动跑一次）。
- 回溯范围可改：默认每个旧会话取最近 **8 轮对话**，也可以切成最近 N 天；在插件设置页选。
- 只扫最近 5 分钟以前、已经写完的会话；当前正在聊的内容不抢。
- 先和现有卡片、知识库对比，已经讲过的点不再生成；角色扮演/文件整理类会话会被跳过。
- 一条历史会话最多产出 0–2 张卡；没有合适素材就输出 0 张。
- 生成引擎顺序可自己排：API / 本地 Ollama / DSH 三档各用一次，在插件设置页选优先顺序；前面的不可用才往后走。
- 生成的卡和普通卡一样进卡片库、占 50 张未学上限；面板里另存一份「历史卡片」记录。
- 实时旁听点过「懂了 / 没懂 / 太简单 / 取下一张」后，也会归到历史卡片里，方便回看。
- 右键会话标题（或「…」菜单）里有「关闭/开启本会话扫描」；关掉后该会话不再送实时旁听，也不参与历史补课。默认开启。

历史补卡需要模型。打开 **插件 → 学习小助手 → 配置**，可以填 API 地址、模型和 API Key、三档优先顺序、回溯轮数/天数；留空 API Key 时不会覆盖已保存的 key，也不会把 key 回传到浏览器。

## 配置

在 profile 的 `cordis.patch.yml` 覆盖：

```yaml
- id: learning-assistant
  config:
    baseURL: http://127.0.0.1:4780
    appDir: ./app
    kbDir: ~/rag
    autoStartOllama: true
    ollamaBin: /opt/homebrew/bin/ollama
```

## 行为

- 只旁听顶层会话；子代理会话不送信号。
- 实时触发不再只等用户发问：助手在任务中讲出「关键/本质/取舍/结论/原则/先…再…」这类判断时，消息一到就本地匹配已有卡片；命中直接出卡/角标，不等这一轮结束。
- 这种主动扫描先查已有卡片，再用知识库做一次 novelty 判断；同会话 5 分钟最多一次，开销最低。
- 卡片、知识库都没命中时，后台用一次**小请求**生成「种子卡」：只有标题、一句结论、逐字引文，面板显示「新知识点」。
- 点「展开细讲」才走完整制卡和引文校验；种子卡不进卡片库、不占 50 张未学上限，展开成完整卡后才计入。
- 种子卡优先用设置里的 API，没有 API 时交给 DSH 内置模型；不会自动用本地 27B。
- 右键会话标题可单独关闭该会话的扫描；关闭后不送实时信号，也不进历史补课。
- 工具层的操作性报错（编辑冲突、被中断、沙箱拒绝等）不送。
- 角标点了才展开；不抢焦点、不出声、不发系统通知。
- 知识卡可「懂了 / 没懂 / 太简单」，知识库条目可「看全文」。
- 面板下方「历史卡片」可展开查看补生成的卡和已处理的旁听记录。
- 没有合适选项的卡（如工作流/判断卡）自动进入「先想后看」模式：不伪造「我不知道」单选项，先在心里过一遍再翻面。
- 面板里的「卡片站」在 DSH 内以浮层打开完整卡片站，不会另开浏览器。
- 卡片站默认跟随 DSH 深浅色；右上角「深色/浅色」可手动切，选择会记住。
- 插件替代原来的 `watch.mjs`；**不要同时跑 watch.mjs**，否则同一信号会送两遍。

## 结构

- `index.js`：Host 半边，监听 `session/event`、转发 detect、注册 `/learning-assistant/*` 同源代理、自动拉起服务；历史补卡在本地/API 都不可用时用 DSH 模型兜底。
- `client.js`：浏览器半边，`shell.overlay` 书本角标、卡片面板、历史卡片区、内嵌卡片站，以及插件页里的模型/API 配置表单。
- `cordis.patch.yml`：一行 Host 占位与默认配置。
